# COACHING-L 音声リピートプレーヤー

端末に保存した音声で、リスニング・シャドーイング・声に出す練習ができるWebアプリです。アカウント登録や教材の準備はいりません。音声はサーバーへ送らず、使っている端末・ブラウザの中だけで扱います。

公開ページ：https://tools.coaching-l.net/audio-loop-player/

開発・テスト・公開の手順は [DEVELOPMENT.md](DEVELOPMENT.md) を見てください。

## できること

基本の流れは「素材を用意する → 練習する」です。どの入口から始めても、同じ練習画面で練習します。

- **音源から始める**：MP3・M4A・WAV など、ブラウザで再生できる音声を10件まで登録できます。次に開いたときも一覧から選ぶだけです。
- **区間をくり返す**：再生ゲージのA・Bを動かして、くり返す範囲を決め、「区間リピート」をONにします。波形が表示され、「前の文へ」「次の文へ」で文ごとに区間を移れます。
- **速度を変える**：0.5〜2.0倍。
- **スクリプトを見ながら聞く**：教材のスクリプトを貼り付けるか、テキストファイル（UTF-8・GB18030）を読み込むと、1文ずつ表示し、再生している文に色が付きます。文を押すとその文をA–B区間にします。スクリプトは「スクリプトを直す」でいつでも直せます。
- **詳しい設定**（ふだんは折りたたんでいます）
  - くり返す回数（無制限・2・3・5・10回）と、くり返しの間の無音（秒数、または「区間と同じ」「区間の1.5倍」「区間の2倍」）。初めは「無制限・無音なし」です。
  - ゲージの拡大・縮小・「区間に合わせる」と、A・Bの時刻の数字での入力。
  - **録音して聞き比べ**：自分の声を録音し、「お手本→自分の声」でA–B区間と続けて聞き比べます。録音は最長60秒で、保存も送信もせず、別の音声を開くと消えます。
  - 文の色の位置がずれるときの「選んだ文の時刻を今のA–Bにする」。
  - **音声から文字起こし**（補助）：スクリプトがないときに、OpenAIのWhisperというモデルで、端末の中で文字にします（英語・中国語）。精度はそこそこなので、必要に応じて手直ししてください。中国語は簡体字で表示します。
- **すぐに戻せる**：音声やスクリプトを削除した直後は、画面下の「元に戻す」で戻せます。
- **画面の外からも操作できる**：ロック画面やイヤホンのボタン、パソコンのキーボード（Space・矢印・A・B・R・[ ]）で操作できます。操作部分を通り過ぎてスクロールすると、画面下に小さなプレーヤーが出ます。

## 機内など、通信のない場所で使う

一度インターネットにつながった状態で開いて音声を保存しておけば、通信なしで起動して練習できます。出発前に、実際に使う端末とブラウザで次を確かめてください。

1. 公開ページを開き、練習する音声を追加して「保存しました」と出ることを確かめます。クラウド上にしかないファイルは、先に端末へダウンロードしてください。
2. 機内モードにしてページをいったん閉じ、同じアドレスを開き直して、再生できるか試します。

画面下の「ご利用にあたって」に、準備ができていないときの案内と「準備をやり直す」があります。新しいバージョンがあると「更新あり」と出るので、インターネットにつながっているときに「新しいバージョンに更新する」を押してください。登録した音声と設定・スクリプトは消えません。

## 保存とプライバシー

- **個人情報（氏名・住所・電話番号・メールアドレスなど）や、人に知られたくない内容を含む音声・スクリプトは、登録しないでください。** 外部へは送りませんが、同じ端末やブラウザを使う人には見えます。
- 音声・設定・スクリプトは、使っている端末・ブラウザの中に保存します。ほかの端末やブラウザとは同期しません。
- 音声を保存すると、ブラウザが自動で消さないように設定を求めます。それでも、ブラウザの履歴・サイトデータを削除すると消えます。**元の音声ファイルは残しておいてください。**
- 外部のサーバー・解析サービス・フォントなどへの通信はありません。ページ自体も、自分のサイトのファイル以外を読み込めない設定（CSP）にしています。
- 文字起こしも端末の中で行い、音声を送りません。初めて文字起こしするときだけ、文字起こし用のデータ（約95MB）をこのサイトから受け取ってブラウザに保存します。一度保存すれば通信なしでも文字起こしでき、「詳しい設定」から削除できます。
- 同じ音声かどうかは「ファイル名・サイズ・最終更新日時」で見分けます。名前を変えたり、編集・再ダウンロードしたりすると、別の音声として扱います。
- Safariのプライベートブラウズでも保存できますが、タブを閉じると消えます。

## うまくいかないとき

- **iPhoneで音声の追加が進まない**：「ファイル」アプリで、音声が端末にダウンロード済みか確かめてください。「音声の読み込みを始める」ボタンが出たら押してください。LINEなどのアプリの中で開いているときは、SafariやChromeで開き直してください。
- **画面を消すと区間がずれる**：画面ロックや別のアプリに切り替えている間は、端末の省電力の仕組みで、区間の終わりや無音の長さがずれることがあります。正確に練習したいときは、画面を開いたままにしてください。
- **区間の終わりがわずかにずれる**：区間の終わりはJavaScriptで見張っているため、数十ミリ秒ほどずれることがあります。とても短い区間には向きません。
- **再生できない音声がある**：拡張子が同じでも、中身の形式や著作権保護（DRM）によって再生できないことがあります。音楽アプリや配信サービスの曲は直接は取り込めません。
- **文字起こしに時間がかかる**：端末の性能によって、音声の長さと同じくらいかそれ以上かかることがあります。スマホでは、メモリを使いすぎないように約30秒ごとに文字起こしのしくみを読み直すため、パソコンより時間がかかります。文字起こしできるのは20分までの音声です。途中で止まるときは、ほかのタブやアプリを閉じてから試してください。古いスマホでは、メモリが足りずに使えないことがあります。
- **録音できない**：ブラウザの設定で、このページにマイクの使用を許可してください。ほかのアプリがマイクを使っていると録音できないことがあります。
- **文字起こしの誤りが多い**：「話している言語」が音声と合っているか確かめてください。雑音や音楽が大きい音声、複数の人が同時に話す音声は苦手です。固有名詞や専門用語は「スクリプトを直す」で直してください。
